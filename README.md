# Carl-Animatronic
O Carl Animatronic é um projeto de robótica inspirado nos personagens animatrônicos de Five Nights at Freddy’s, desenvolvido para explorar a integração entre mecânica, eletrônica e programação embarcada.

O personagem possui movimentação dos olhos e da boca através de servomotores, iluminação dinâmica simulando uma vela e reprodução de efeitos sonoros, criando uma experiência interativa e imersiva.

O projeto aplica conceitos de controle de atuadores, programação de microcontroladores e desenvolvimento de sistemas embarcados, demonstrando como a robótica pode ser utilizada na criação de personagens autônomos para entretenimento e experiências tecnológicas.
